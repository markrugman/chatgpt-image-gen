# Image Gen

**Your images deserve a home of their own.**

Image Gen is a dedicated workspace for creating, refining and organising AI-generated images with your ChatGPT account. Keep your artwork, design conversations and earlier versions together—from your first idea to the finished export.

## Create and refine

Generate images from a description, use reference images to guide the result, or discuss ideas before creating anything. Develop posters, illustrations, social content and other artwork through an ongoing conversation.

Refine an entire image or mark areas you want to change. Compare alternatives and return to earlier versions whenever you want to explore a different direction.

## Keep your work organised

Group work into **organisations** for different clients, businesses or personal interests, then use **projects** to organise campaigns, events and ideas.

Each design can contain multiple pages, with its images, conversations and revision history kept together. Searchable tags help you find and reuse your work as your collection grows.

## Build on what you already have

Keep reusable artwork in asset libraries and bring your own photographs, logos and images into your designs. Use them as references for generation or place the original images directly onto the canvas.

Arrange and combine images into finished compositions, extract reusable elements from existing artwork, and save templates for prompts you use regularly.

## Export for screen or print

Create designs at standard or custom sizes. Export individual pages as **PNG or JPEG**, or complete documents as **multi-page PDFs**.

For print work, export options include bleed, crop marks and RGB or CMYK output.

## Choose how you work

- **Windows app:** create and manage designs in a standalone desktop workspace.
- **Self-hosted browser workspace:** access your designs through a browser and connect desktop installations to shared storage.
- **Optional Codex companion:** start a design from a Codex chat, then continue working on it in Image Gen.

The Windows app includes the runtime needed for image generation. Sign in with ChatGPT inside Image Gen to get started.

## Get started

Download the Windows installer or portable app from [GitHub Releases](https://github.com/markrugman/chatgpt-image-gen/releases).

Install and open Image Gen, sign in with ChatGPT through **Settings**, then create an organisation, project and design. Describe what you want to make and start generating.

For browser access or shared storage, follow the [self-hosted server guide](docs/SELF-HOSTED-SERVER.md). The optional Codex companion is also available from the releases page.
